# 税后收入计算（北京 · 2026 · 累计预扣法）

一个零依赖（除 openpyxl 外）的小工具：在 Excel 里维护自己的工资数据，脚本按个税**累计预扣法**算出每月应预扣税额与税后到手收入，并把结果**写回同一个 xlsx 的新增列**，与工资单自动核对。

> 🔒 **代码仓库不含任何工资数据**：所有真实数字只存在于你本地的 `工资表.xlsx`（已通过 `.gitignore` 排除），本仓库可放心公开。

## 特性

- 数据与代码分离：脚本可分享、可开源，数字留在本地
- 结果按列追加进 xlsx，重跑按表头原地覆盖，**幂等**不重复加列
- 逐月核对：计算税额 vs 工资单实际个税，差异不为 0 立即提示
- 支持年中奖金（进累计不进单月）、专项附加扣除中途取消等真实场景

## 快速开始

```bash
pip install openpyxl
cp 工资表_模板.xlsx 工资表.xlsx     # 或按格式维护自己的表格
python 税后收入计算_表格版.py       # 结果自动写回 xlsx
```

也可指定其他文件：`python 税后收入计算_表格版.py 我的工资表.xlsx`

## xlsx 输入格式

第 1 行为表头（列序不限，按名称识别），每行一个月：

| 列名 | 含义 |
|---|---|
| 月份 | 当年第几个月（1–12） |
| 本月税前收入 | 工资条“税前收入” |
| 累计税前收入 | 个税 APP / 工资条“累计收入” |
| 实际个税 | 工资条“本月个税”，用于核对 |
| 累计专项附加扣除 | 本月申报口径的累计值；取消后填 0 |
| 每月五险一金 | 个人缴纳部分（逐月可不同） |

## 输出

脚本从第一个空列起追加 12 个计算列：累计减除费用、累计五险一金、累计收入差异、累计应纳税所得额、适用税率、速算扣除数、累计应纳税额、上月累计已纳税、本月应纳税额(计算)、与工资单差异、税后收入(计算)、税后收入(实际)。

控制台仅输出简报（写入位置、异常月份提醒），不回显文档已有内容。

## 计算口径

```
累计应纳税所得额 = 累计税前收入 − 5000×月数 − 累计五险一金(个人) − 累计专项附加扣除
本月应纳税额     = 累计应纳税额 − 之前月已纳税额（<0 取 0）
本月税后收入     = 本月税前收入 − 本月五险一金 − 本月应纳税额
```

预扣率表为综合所得年度 7 级（3%–45%），政策调整时可修改脚本顶部 `TAX_BRACKETS`。

详细规则、示例解读与限制说明见 [docs/使用说明.md](docs/使用说明.md)。

## 范围外

年终奖单独计税、股权激励、企业年金、五险一金基数上下限校验暂不涉及。
